# Häufige Fragen

## Wie ändere ich eine Seite?

Öffne die entsprechende `.md`-Datei im Ordner `docs`, bearbeite den Text und speichere die Änderung.

## Wann erscheint eine Änderung online?

Wenn du deine Änderung in den Branch `main` übernimmst, startet GitHub Actions die Veröffentlichung.
