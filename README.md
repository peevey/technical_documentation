# MkDocs-Testprojekt (3 Seiten)

1. Neues GitHub-Repository mit Branch `main` erstellen.
2. Den Inhalt dieses Ordners ins Stammverzeichnis des Repositorys hochladen, auch den versteckten Ordner `.github`.
3. Unter **Settings → Pages → Build and deployment → Source** die Option **GitHub Actions** wählen.
4. Unter **Actions** den Workflow **Dokumentation veröffentlichen** prüfen. Sobald er erfolgreich abgeschlossen ist, erscheint unter **Settings → Pages** die URL zur Website.

Optional lokal: `pip install mkdocs-material` und danach `mkdocs serve` starten; Vorschau unter http://127.0.0.1:8000/.

Hinweis: Vor einer Nutzung für interne oder vertrauliche Inhalte die Sichtbarkeit der GitHub-Pages-Website prüfen.
